# Early Foods

Early foods is an e-commerce application where you can buy healthy and millet based products for your kids and mother such as jaggery cookies, porridges, katori cake mixes, A2 ghee laddoos.

## Features

- **Landing page** with a list of featured categories and newly added products
- **Product listing page** where all the products are listed with a section of filters
    - Category
    - Price range
    - Rating
    - Sort by price
    - Clear filter button
- Product details page
- Cart Management
- Wishlist Management
- Address Management
- User Profile
- Checkout

## Technology Stack

- **Frontend** - Reactjs (with Vite), React Router v6, Bootstrap 5.3, Bootstrap icons, React hot toast, Chart.js
- **State management** - Redux toolkit
- **Backend -** Node.js, Express.js
- **Database -** MongoDB, Mongoose
- **Deployment -** Vercel

## Installation
```
git clone https://github.com/priyanka-s12/early_foods_frontend.git
cd early_foods_frontend
npm install
npm run dev
```
